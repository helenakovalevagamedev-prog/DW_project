\## Заметки для команды разработки



**Сроки**: выполнение задания заняло с понедельника по пятницу + добавление анимации и подготовка к отправке в воскресенье.



**Фреймворк Naninovel** был для меня незнакомым — значительная часть времени ушла на изучение самого фреймворка и правку багов, связанных именно с его использованием.



**Осознанные допущения от текста задания** - не меняют сути, но в данном случае визуально делают игру более приятной:

\- Персонаж в диалоге размещён справа, а не по центру экрана.

\- Перемещение по локациям ограничено изначально — кнопки перехода появляются по мере повествования. После этого перемещение между уже открытыми локациями свободное.

\## Архитектура



\### Кастомные сервисы:

\- **InventoryService** — хранит предметы игрока (ключ, предмет из сейфа), поддерживает сохранение/загрузку состояния.

\- **TicTacToeService** — логика мини-игры: состояние поля 3×3, простой ИИ, определение победителя/ничьей.



\### Кастомные команды:

* @addItem/@removeItem - Управление инвентарём
* @startMinigame - Запуск крестиков-ноликов, ожидание результата, запись в custom variable
* @startNewGame - Сброс прогресса и переход в стартовую локацию (вызывается встроенным Title UI)
* @hideWorldCharacter/ @showWorldCharacter - скрытие/показ фонового интерактивного НПЦ на время диалога
* @hideArrows/ @showArrows - Скрытие/показ стрелок перехода между локациями на время диалога
* @disableKey/ @enableKey - Блокировка повторного клика по ключу во время мини-игры



\### Контроллеры сцены - обычные MonoBehaviour. Дополнительные вспомогательные классы (Enum, consts, states, spots и тп.) не указаны.

\- **Main** — оркестратор: обрабатывает клики по НПЦ/сейфу/ключу, хранит текущую локацию и общее состояние GameState, рассылает события подписчикам.

\- **UIController** — стрелки перехода между локациями, иконка предмета в инвентаре.

\- **DisplayController** — видимость фонового НПЦ/сейфа/ключа по локации, анимация персонажа (грусть/радость) через Animator.

\- **TicTacToeUI** - настройка отображение мини-игры.

\## Как запустить и проверить



\### Unity Editor

1\. Открыть сцену MainScene, нажать Play.

2\. На титульном экране нажать New Game.

3\. Пройти квест: поговорить с НПЦ → найти сейф на Локации-2 → найти ключ на Локации-3 → выиграть в крестики-нолики → вернуться и открыть сейф → вернуться к НПЦ с предметом.

4\. Для повторного прохождения — остановить и заново запустить Play Mode (New Game сознательно не реализована из-за нестабильности встроенной команды @title).



\### Build

1. На титульном экране нажать New Game.

2\. Пройти квест: поговорить с НПЦ → найти сейф на Локации-2 → найти ключ на Локации-3 → выиграть в крестики-нолики → вернуться и открыть сейф → вернуться к НПЦ с предметом.

4\. Для повторного прохождения — нажать Exit и заново запустить файл .exe (New Game сознательно не реализована из-за нестабильности встроенной команды @title).
